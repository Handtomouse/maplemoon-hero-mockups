### P1 — Designer Call (NOT auto-fixed) 🔴

- **`hero-overlay` + `hero-bg::after` double-darkening** (lines 58–82):
  `.hero-bg::after` applies navy gradient from bottom (to 20% at top). `.hero-overlay` applies
  `linear-gradient(to bottom, transparent 55%, rgba(0,0,0,0.65))` starting at 55%. Combined, they
  stack in the lower half: navy 0.4–0.6 + black 0.65. Photo is effectively buried below 55%.
  Text is very legible (intentionally dark), but photo visibility below fold is sacrificed.
  **🔴 REVIEW — if photo visibility in lower third matters, remove `.hero-overlay` (line 317) and
  rely solely on `hero-bg::after`. Decision: Nate / designer.**

### P2 — Outstanding

- **`hero-overlay` uses `rgba(0,0,0,0.65)` pure black** (line 71, inside `.hero-overlay`): pure black
  is off-palette. If keeping `.hero-overlay`, replace with `--mm-navy-50` or define `--mm-navy-70`
  to maintain brand warmth.
- **Two `rgba(30,67,102,...)` values in `hero-bg::after`** — `rgba(30,67,102,0.4)` and
  `rgba(30,67,102,0.6)` — should use tokens. Define `--mm-navy-40` and `--mm-navy-60` in brand_kit.css.

### P2 — RESOLVED (confirmed in this session)

- **`background-attachment: fixed` + CSS `filter` conflict** → `background-attachment: fixed` removed (line 65 comment confirms). ✅
- **Trust icon filter inconsistent with V10/V11** → line 190 now uses the richer cream filter matching V10. ✅

### P3 — Outstanding

- **`kenBurns` animation is pure zoom, no pan** — same note as V12. Add subtle translate.
- **Watermark `z-index: 1` may render above `hero-overlay` at same z-index** — low risk at `opacity: 0.04` but worth a visual check on first load.

### Keep as-is

- Full-bleed lifestyle photo: the strongest editorial concept in the series.
- Desktop `text-align: left` bottom-left positioning: correct.
- CTA hover: cream + navy — on-palette, clean.
- `back-link` visible on both viewports (not hidden on mobile — correct for this concept).
- Mobile menu consistent with V11/V12.
- `fetchpriority` not set on CSS background image — correct (preload handles it).
