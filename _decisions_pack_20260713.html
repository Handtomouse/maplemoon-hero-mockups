Internal note: font licensing (blocker before any deploy)

The demo runs on unlicensed demo cuts. Both families must be licensed or swapped before anything goes public.

  • P22 Mackinac Pro (serif, headings): loaded via local() against the installed "FONTSPRING DEMO" cuts. Demo licence does not cover web use. Buy the webfont from Fontspring, or swap.
  • Neue Haas Grotesk Display Pro (sans, body): also resolved via local() from the machine. Web use needs a Monotype webfont licence, or it is available through Adobe Fonts with a CC subscription (check web-project embed terms), or swap to a licensed near-match.
  • Because both load via local(), the demo only renders correctly on this machine. Fallbacks are Georgia / Helvetica. This is fine for tonight's local walkthrough, and one more reason the demo must not be deployed as-is.

Not a Carli/Dylan decision tonight; it is our pre-deploy checklist item and a cost line to budget for.
