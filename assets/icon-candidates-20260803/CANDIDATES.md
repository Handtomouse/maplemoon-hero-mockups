# W1-E icon-source candidates — 2026-08-03

## Boundary

This is sourcing only. No third-party artwork has been downloaded, copied, recoloured, or wired.
The existing MapleMoon icon system remains authoritative: `250 x 250`, cream `#e7e4ca`, filled
paths, no strokes, with a simplified small-size cut for navigation.

All three sets below are visual/reference candidates, not approved production assets. Before any
licence purchase or commissioning, Nate must choose a direction and confirm whether it may depart
from the existing filled MapleMoon system.

## Candidate A — Streamline Freehand (recommended as a reference direction)

- Source: [chocolate-bar search](https://www.streamlinehq.com/icons/tag/chocolate-bars) and
  [banana search](https://www.streamlinehq.com/icons/tag/banana).
- Set family: **Freehand**. Its searchable catalogue covers the needed anchor concepts:
  chocolate bar, banana, crescent/moon, round truffle/eclipse bite, and bottle/elixir.
- Why it is strongest: a single loose illustrative family can provide a consistent silhouette
  reference across the five categories.
- Fit gate: its output must be re-illustrated as cream filled paths; do not use its generic
  line, duotone, or multicolour glyphs directly.

## Candidate B — Envato Hand-Drawn Foods Icon Set

- Source: [Hand-Drawn Foods Icon Set](https://elements.envato.com/hand-drawn-foods-icon-set-G7PPNKT).
- Set family: 100 hand-drawn food icons in AI, EPS, PNG and SVG, listed with a commercial
  licence.
- Why it is useful: a broad, coherent food-illustration library for bar, banana, rounded bite,
  and bottle motifs; it can be evaluated as one visual direction rather than mixed makers.
- Fit gate: check the purchased set includes a crescent and the exact bite silhouette before
  buying; neither is verified from the public listing. Rework would still be required to match
  MapleMoon's monochrome filled system.

## Candidate C — Creative Fabrica Hand Drawn Food Icon Set

- Source: [Hand Drawn Food Icon Set](https://www.creativefabrica.com/product/hand-drawn-food-icon-set/).
- Set family: snack, dessert and street-food vectors in SVG, EPS, JPG and PNG; public listing
  states a commercial licence is included.
- Why it is useful: its hand-drawn food language gives an alternative, more playful reference
  to test against A and B.
- Fit gate: this is line art, so it conflicts with the existing solid-fill MapleMoon assets.
  Treat it as a rejectable reference direction only, never a drop-in set.

## Decision card for Nate

1. **A — Streamline Freehand:** closest shape direction; commission/redraw the exact five marks.
2. **B — Envato:** broadest single commercial food family; verify moon/eclipse coverage first.
3. **C — Creative Fabrica:** most playful; only choose if the brand intentionally permits a
   line-art departure.

No option is ready to ship unchanged. The approved production path must still include five
MapleMoon-native `250 x 250` SVGs plus simplified small-size cuts.
